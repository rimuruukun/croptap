# src/lib/storage

Student-friendly guide for this folder.

## What this folder is for
Storage architecture documentation for canonical local and remote data boundaries.

## Files in this folder
- CANONICAL_DATA_TABLE.md: This is a Markdown text file in src/lib/storage. Its main purpose is this: main saved data table contract between local records and the online database documents. It handles the day-to-day tasks for this area, so nearby files can rely on one clear place for this work. Without this file, this part of the app would miss an important step and features here could break or behave in confusing ways.
## Student tips
- Start from this README, then open the files listed above in order.
- If you change responsibilities in this folder, update this README in the same commit.
- Prefer small, focused edits so behavior stays easy to reason about.
