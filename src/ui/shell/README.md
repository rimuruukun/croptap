# src/ui/shell

Student-friendly guide for this folder.

## What this folder is for
App shell components such as header and navigation.

## Files in this folder
- SharedHeader.jsx: This is a React component file in src/ui/shell. Its main purpose is this: Top app header showing currencies, save status, network, and save and online update status. It handles the day-to-day tasks for this area, so nearby files can rely on one clear place for this work. Without this file, this part of the app would miss an important step and features here could break or behave in confusing ways.
- SharedNavigation.jsx: This is a React component file in src/ui/shell. Its main purpose is this: Primary navigation component for section switching. It handles the day-to-day tasks for this area, so nearby files can rely on one clear place for this work. Without this file, this part of the app would miss an important step and features here could break or behave in confusing ways.
## Student tips
- Start from this README, then open the files listed above in order.
- If you change responsibilities in this folder, update this README in the same commit.
- Prefer small, focused edits so behavior stays easy to reason about.
