# src/ui

Student-friendly guide for this folder.

## What this folder is for
Presentation-focused UI components grouped by app surface area.

## Subfolders and what they do
- auth/: Authentication page and related UI states.
- common/: Shared lightweight UI primitives used by multiple sections.
- shell/: App shell components such as header and navigation.

## Files in this folder
This folder mainly organizes subfolders, so most code lives one level deeper.

## Student tips
- Start from this README, then open the files listed above in order.
- If you change responsibilities in this folder, update this README in the same commit.
- Prefer small, focused edits so behavior stays easy to reason about.
