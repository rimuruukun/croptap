# src/features/game

Student-friendly guide for this folder.

## What this folder is for
Gameplay feature bundle containing reusable UI components, config, section screens, and economy helpers.

## Subfolders and what they do
- components/: Reusable gameplay UI controls used by management and upgrade flows.
- config/: Static gameplay and navigation configuration constants.
- sections/: Top-level gameplay section screens rendered through app routing and section switching.
- utils/: Gameplay math and formatting helpers for purchases and currency display.

## Files in this folder
This folder mainly organizes subfolders, so most code lives one level deeper.

## Student tips
- Start from this README, then open the files listed above in order.
- If you change responsibilities in this folder, update this README in the same commit.
- Prefer small, focused edits so behavior stays easy to reason about.
