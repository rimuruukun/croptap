# src/features/game/components

Student-friendly guide for this folder.

## What this folder is for
Reusable gameplay UI controls used by management and upgrade flows.

## Files in this folder
- QuantityControls.jsx: This is a React component file in src/features/game/components. Its main purpose is this: Buy-quantity selector control for upgrade and hiring actions. It handles the day-to-day tasks for this area, so nearby files can rely on one clear place for this work. Without this file, this part of the app would miss an important step and features here could break or behave in confusing ways.
- SectionSwitch.jsx: This is a React component file in src/features/game/components. Its main purpose is this: Tools/Farmers section toggle used in management screens. It handles the day-to-day tasks for this area, so nearby files can rely on one clear place for this work. Without this file, this part of the app would miss an important step and features here could break or behave in confusing ways.
- UpgradeCard.jsx: This is a React component file in src/features/game/components. Its main purpose is this: Reusable card component for tool upgrades and farmer hiring actions. It handles the day-to-day tasks for this area, so nearby files can rely on one clear place for this work. Without this file, this part of the app would miss an important step and features here could break or behave in confusing ways.
## Student tips
- Start from this README, then open the files listed above in order.
